# 🧩 Scrabble Helper

A simple, elegant word suggestion tool built to assist Scrabble players. Enter your letters, adjust filters like word length or required positions, and get scoring-optimized word suggestions instantly — now with wildcard support and advanced filtering!

[🌐 Live Site →](https://w0nght.github.io/scrabble_helper/)

---

## ✨ Features

- 🔡 **Letter Input & Filtering**  
  - Enter up to 15 letters (A-Z only).  
  - Include 0, 1, or 2 wildcards using toggle buttons.  
  - Filter results by word length with a flexible dual-handle range slider (2–15 letters).  
  - Require a specific letter at a particular position (1–12).  

- 🔢 **Sort Results**  
  - Alphabetically (A to Z)  
  - By word score (high to low)  
  - By word length (short to long or long to short)

- 🎨 **Dark Mode / Light Mode Toggle**  
  Switch themes instantly, with your preference saved for next visit.

- 🔄 **Reset Filters**  
  Quickly clear all filters and results with a smooth animation.

- 🔍 **Responsive Design & Accessibility**  
  Works great on mobile and desktop, with keyboard accessible inputs and buttons.

- 🧩 **Scrabble-style Flip Tile Animations**  
  Enjoy visually appealing animations while searching.

- 🛠️ **Built With:**  
  - HTML5 / CSS3 (with CSS variables & noUiSlider)  
  - JavaScript (vanilla ES6+)  
  - JSON dictionary: `Collins_2019.json`
